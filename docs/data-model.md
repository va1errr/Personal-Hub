# Data Model

## Table: users

| Column        | Type          | Constraints                                    |
|---------------|---------------|------------------------------------------------|
| `id`          | `BIGINT`      | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` |
| `tg_user_id`  | `BIGINT`      | `NOT NULL UNIQUE`                              |
| `tg_username` | `TEXT`        |                                                |
| `created_at`  | `TIMESTAMPTZ` | `NOT NULL DEFAULT now()`                       |

## Table: user_settings

| Column     | Type     | Constraints                                 |
|------------|----------|---------------------------------------------|
| `user_id`  | `BIGINT` | `NOT NULL PRIMARY KEY REFERENCES users(id)` |
| `timezone` | `TEXT`   | `NOT NULL`                                  |

## Table: inbox_items

| Column       | Type          | Constraints                                    |
|--------------|---------------|------------------------------------------------|
| `id`         | `BIGINT`      | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` |
| `user_id`    | `BIGINT`      | `NOT NULL REFERENCES users(id)`                |
| `content`    | `TEXT`        | `NOT NULL`                                     |
| `status`     | `TEXT`        | `NOT NULL DEFAULT 'ACTIVE'`                    |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL DEFAULT now()`                       |

### Constraints

- check `status` if it is in enum

## Table: tasks

| Column          | Type          | Constraints                                    |
|-----------------|---------------|------------------------------------------------|
| `id`            | `BIGINT`      | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` |
| `user_id`       | `BIGINT`      | `NOT NULL REFERENCES users(id)`                |
| `inbox_item_id` | `BIGINT`      | `REFERENCES inbox_items(id)`                   |
| `title`         | `TEXT`        | `NOT NULL`                                     |
| `description`   | `TEXT`        |                                                |
| `priority`      | `TEXT`        | `NOT NULL`                                     |
| `status`        | `TEXT`        | `NOT NULL DEFAULT 'OPEN'`                      |
| `created_at`    | `TIMESTAMPTZ` | `NOT NULL DEFAULT now()`                       |
| `due_at`        | `TIMESTAMPTZ` |                                                |
| `completed_at`  | `TIMESTAMPTZ` |                                                |

### Constraints

- check `priority` if it is in enum
- check `status` if it is in enum

## Table: notes

| Column          | Type          | Constraints                                    |
|-----------------|---------------|------------------------------------------------|
| `id`            | `BIGINT`      | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` |
| `user_id`       | `BIGINT`      | `NOT NULL REFERENCES users(id)`                |
| `inbox_item_id` | `BIGINT`      | `REFERENCES inbox_items(id)`                   |
| `content`       | `TEXT`        | `NOT NULL`                                     |
| `created_at`    | `TIMESTAMPTZ` | `NOT NULL DEFAULT now()`                       |

## Table: note_tags

| Column    | Type     | Constraints                                    |
|-----------|----------|------------------------------------------------|
| `id`      | `BIGINT` | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` |
| `user_id` | `BIGINT` | `NOT NULL REFERENCES users(id)`                |
| `tag`     | `TEXT`   | `NOT NULL`                                     |

### Constraints

- UNIQUE (`user_id`, `tag`)

## Table: note_to_tag

| Column    | Type     | Constraints                         |
|-----------|----------|-------------------------------------|
| `note_id` | `BIGINT` | `NOT NULL REFERENCES notes(id)`     |
| `tag_id`  | `BIGINT` | `NOT NULL REFERENCES note_tags(id)` |

### Constraints

- PRIMARY KEY (`note_id`, `tag_id`)
